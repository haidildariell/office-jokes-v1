## The joke

> I hit reply-all by accident once, and now my inbox holds 47 apologies, one resignation, and a calendar invite titled Please Stop Replying All.

## How it works

`main.py` (Python 3.13, no dependencies, no network) writes the joke to
`/output/entry.txt`, after validating the entry gate: a single non-blank
line of 1-199 characters.

Run it with:

```sh
python3 main.py
```
